# Human History — التاريخ البشري

أداة ويب مجانية مفتوحة المصدر تجمع ما كتبه البشر عن ماضيهم على خريطة وخط زمني واحد، وتنسب كل معلومة إلى مصدرها مع درجة ثبوتها (نص، رواية، قول، تقدير، غير معروف).

## ما في الموقع الآن
- **الخريطة والزمن:** من 7000 ق.م إلى اليوم، ومع كل سنة: الشخصيات الحية وأعمارها، والحضارات المعاصرة (تضغطها فتقرأ قصتها)، والسور النازلة.
- **الشخصيات:** مسارات نوح وإبراهيم ويوسف وموسى وعيسى ومحمد ﷺ (59 محطة) على الخريطة. في كل محطة: السنة والعمر (تقدير الأداة)، وكل الأقوال في موضعها، وما قاله القرآن والصحيحان والتوراة والمدراش والمفسرون، مع رابط يفتح النص.
- **مقارنة الروايات:** الطوفان في 6 روايات بالموتيفات (Thompson A1010)، وقاموس الأسماء.
- **النصوص:** القرآن كاملًا (بترتيب النزول والمصحف) والكتاب المقدس كاملًا (فان دايك، 66 سفرًا).
- القرآن والصحيحان مميزان بالأبيض والأخضر، وكل تقدير من الأداة موسوم بذلك.

## التشغيل محليًا
```
npx http-server -p 8790
```
ثم افتح http://127.0.0.1:8790. الموقع ثابت بالكامل ويعمل على GitHub Pages.

## البيانات
- `data/quran/` تُبنى بـ `scripts/build_quran.py` من Quran.com API v4 (بيانات Tanzil للترتيب والمكان).
- `data/bible/` تُبنى بـ `scripts/build_bible.py` من ترجمة فان دايك (ملك عام) عبر bible.helloao.org.
- `data/people.json`: الشخصيات ومحطاتها.
- `data/events.json`: الأماكن والأحداث والحضارات وقصصها. كل ادعاء: `text`, `certainty`, `source`. الحالة `draft` تعني أنه لم يُراجَع.
