# قصص إيش ما كان

أداة ويب مجانية مفتوحة المصدر تجمع ما كتبه البشر عن ماضيهم على خريطة وخط زمني واحد، وتنسب كل معلومة إلى مصدرها مع درجة ثبوتها (نص، رواية، قول، تقدير، غير معروف).

## المرحلة 1 (هذا الإصدار)
- خريطة (MapLibre + OpenFreeMap) وخط زمني من 3000 ق.م إلى اليوم، مع ما كان يجري في بقية العالم في السنة المختارة.
- القرآن كاملًا (6236 آية، الرسم العثماني) بترتيب النزول وترتيب المصحف، مع مكان النزول، وتمييز مكان النزول عن مكان الحدث.
- مثال تجريبي: عام الفيل (مسودة قيد المراجعة).

## التشغيل محليًا
```
npx http-server -p 8790
```
ثم افتح http://127.0.0.1:8790. الموقع ثابت بالكامل ويعمل على GitHub Pages.

## البيانات
- `data/quran/` تُبنى بـ `scripts/build_quran.py` من Quran.com API v4 (بيانات Tanzil للترتيب والمكان).
- `data/events.json`: الأماكن والأحداث والادعاءات. كل ادعاء: `text`, `certainty`, `source`. الحالة `draft` تعني أنه لم يُراجَع.

## قبل النشر العام
- التحقق من رخصة نص المصحف (Tanzil: CC BY 3.0 بشرط عدم التعديل) وبيانات Quran.com.
- اختيار رخصة المشروع (مثل MIT للكود و CC BY-SA للبيانات).
